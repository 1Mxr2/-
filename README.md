# 神魔远征 · Mythic Odyssey

像素风 2D 闯关游戏：东方与西方的神仙妖怪拦路，五重天地等你闯荡。
纯 HTML5 + Canvas，零依赖，**双击 `index.html` 即可游玩**（也可用任意静态服务器打开）。

**无敌版**：双击 `index-god.html`——直接进入懦夫模式，全程不会受到任何伤害，且**武器伤害 ×5**（界面有 ★无敌 标识），适合想爽快割草或纯看关卡与 Boss 演出的玩家。

点击主界面的「开始征战」后，可选择两种模式：**勇者模式**固定普通数值（伤害 ×1、无敌关闭）；**懦夫模式**可以在设置中调整伤害倍率并开启或关闭无敌。

五关 Boss 的总血量已调整为逐关递增的 90 / 100 / 110 / 130 / 150（原设定的一半）。后面章节会逐步加入更多招式：蛛母的万毒天降、判官的墨影闪斩、炎魔的陨火连坠与炼狱火环，最终 Boss 保留最多的多形态技能。

## 玩法

- 每关一路向右闯关，**击败关卡最右边的 BOSS**，传送门才会解封，走进传送门进入下一关。
- 血量是**几颗心**（初始 3 颗，上限 5），另有**三条命**；命尽可在当前关重来。
- 敌人的攻击会附加**坏效果**；好神仙/好妖怪会赠送**神秘效果**。

| 坏效果 | 来源举例 | 效果 |
|---|---|---|
| 中毒 | 蜘蛛妖、蛛母毒液 | 持续掉血 |
| 灼烧 | 地狱犬、岩浆、炎魔 | 持续掉血 |
| 寒冰 | 冰霜妖灵、蛛网 | 移速减半 |
| 诅咒 | 判官墨弹、堕落天使 | 攻击减半、出手变慢 |

| 好效果 | 赠予者 | 效果 |
|---|---|---|
| 回春 | 药童 | 回 1 颗心并解除所有异常 |
| 疾风 | 风灵 | 加速 + 二段跳（12 秒） |
| 神佑 | 土地公 / 治愈天使 | 抵挡 3 次伤害的护盾 |
| 忘忧汤 | 孟婆 | 回满心 + 无敌 6 秒 |
| 金刚之力 | 金刚力士 | 攻击翻倍（12 秒） |

站在神仙身边按 `E` 交谈即可获得赠送（每关各一次）。

## 操作

| 按键 | 功能 |
|---|---|
| `←` `→` / `A` `D` | 移动 |
| `空格` | 跳跃（疾风状态下可二段跳；长按跳更高） |
| `J` / `Z` | 攻击（支持冷却缓冲连按） |
| `按住 ↑` + `J` | **向上攻击**（上挥 / 上射，打飞行怪） |
| `空中按住 ↓` + `J` | **向下攻击** |
| `E` | 与神仙交谈（加护每位只赠一次） |
| `Q` 或 `1`-`6` | 切换武器：青铜剑(2) / 飞剑(1) / 圣光弩(1) / 雷火符(2·爆) / **雷霆之刃(2+雷电波)** / **炎狱双刃(2+火焰波)** |
| `P` | 暂停并打开设置 |
| `Esc` | 任意时候打开设置；设置中可退出到主界面 |
| `M` | 静音 |
| `H` | 主界面打开**操作说明**（标题页与设置页的上下选择也支持 `W`/`S`） |

调试键（チート）：`F8` 跳关，`F9` 在懦夫模式下切换无敌。

六把神兵都带独立的手持造型、挥击辉光与像素图标；雷霆之刃挥击会甩出一道**短程雷电波**，炎狱双刃会甩出一道**火焰舌**——两把神器在 ↑ 上挥 / ↓ 下劈 / 平推三个方向都能放出刀气。
标题曲 + 三首可选战斗曲（**热血战曲 / 云海谣 / 幽冥葬歌**）各有独立的音色、调式与节奏型，非同一旋律变速。

## 五重天地

1. **云海天梯**（天界外域）—— 天兵、小恶魔、石像鬼 → BOSS 石像鬼王（足踏符文石环）
2. **幽冥洞窟**（地脉深处）—— 骷髅弓手、蜘蛛妖、冰霜妖灵 → BOSS 蛛母·千目（垂丝悬空）
3. **炼狱十八层**（幽冥鬼府）—— 地狱犬、鬼火、牛头、马面 → BOSS 判官·笔墨无情（脚踏墨云）
4. **圣殿遗迹**（西天神域）—— 堕落天使、石像鬼、地狱犬 → BOSS 炎魔·焚世（双环火轮）
5. **神魔之巅**（混沌王座）—— 全妖魔大杂烩 → 最终 BOSS 混沌魔神（混沌法印 · 三形态）

路牌会提示机关与 BOSS 情报；屏幕边缘的金色箭头始终指向当前任务目标。

## 开发

```
index.html        入口（960x540 背板，2x 逻辑分辨率 + 整数倍缩放，像素锐利）
js/sprites.js     全部像素精灵（字符串画 + 自动描边）与程序化图块
js/data.js        武器 / 敌人 / Boss / 神仙 / 五关地图（程序化地图构建器）
js/game.js        引擎：物理、战斗、Boss AI、状态效果、HUD、音效（WebAudio 合成）
test/smoke.js     Node 冒烟测试（DOM/Canvas 桩）：闯关、Boss 击杀、状态效果、死亡重生
```

跑测试：`node test/smoke.js`
